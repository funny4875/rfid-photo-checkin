# RFID 出勤登記系統規格

## 目標

建立一個可在本機或校內伺服器執行的小型 HTTP server，提供網頁式出勤登記系統。使用者輸入自己的學號後，系統查詢學生資料、顯示照片與資料，並依選擇的場域與刷進/刷出狀態寫入門禁記錄文字檔。

## 執行環境

- 使用 Python Flask 建立本地 HTTP server。
- 預設在本機執行，例如 `http://127.0.0.1:5000`。
- 專案根目錄依部署環境而定。

## 前台畫面

前台需要包含以下區塊：

- 學號輸入框。
- 圖片顯示區。
- 資料顯示區。
- 今日記錄列表，可選取其中一筆記錄。
- 刪除按鈕，用來刪除選取的今日記錄。
- 選項框：`刷進`、`刷出`。
- 場域顯示：由 `場域對應.txt` 決定，例如 `警衛室`、`教官室`。

## 登記流程

1. 使用者在輸入框輸入自己的學號。
2. 使用者按 Enter 後送出登記。
3. 系統以學號查詢 `student_data.txt`。
4. 若學號存在：
   - 顯示學生照片。
   - 顯示學生資料。
   - 寫入對應機台的門禁記錄檔。
   - 清空輸入框，方便下一位使用者輸入。
5. 若學號不在資料庫中：
   - 前端顯示 alert。
   - 不寫入門禁記錄。

## RFID 自動登記流程

1. 系統啟動時，在背景偵測 Windows PC/SC 讀卡機，支援 ACR122U。
2. ACR122U 讀到卡片時，系統取得卡片 HEX UID。
3. 前端將 HEX UID 轉換後的十進位分段 UID 與目前選取的 `機台`、`刷進/刷出` 送到後端。
4. 後端以十進位分段 UID 比對 `student_data.txt` 的 `UID` 欄位。
5. 若 UID 存在：
   - 顯示學生照片。
   - 顯示學生資料。
   - 寫入對應機台的門禁記錄檔。
6. 若 UID 不存在：
   - 顯示 `noUID.jpg`。
   - 顯示未建檔 UID。
   - 不寫入門禁記錄。

## 前台刪除今日記錄

前台需要顯示目前所選機台的今日門禁記錄列表。

刪除流程：

1. 使用者在今日記錄列表中選取一筆記錄。
2. 使用者按 Delete 鍵或點選刪除按鈕。
3. 系統先顯示確認訊息，詢問是否確定刪除該筆記錄。
4. 使用者確認後，才從今日對應機台的門禁記錄檔中刪除該筆資料。
5. 使用者取消時，不刪除任何資料。

刪除限制：

- 只允許刪除今日記錄。
- 只刪除目前選取機台的記錄檔內容。
- 一次只刪除一筆選取的記錄。

## 學生資料

學生資料來源為根目錄的 `student_data.txt`。

檔案使用 tab 分隔，欄位如下：

```text
編號	UID	學號	座號	班級	姓名
```

登記時以 `學號` 欄位查詢資料。

若 `UID` 是空值或 `?????:?????`，門禁記錄中的卡片 UID 欄位寫入 `?`。

座號顯示與記錄格式為 `16號` 這類格式。

## 照片顯示

- 學生照片放在子資料夾 `ccsh_data`。
- 優先讀取：
  - `ccsh_data/<學號>.jpg`
  - `ccsh_data/<學號>.JPG`
- 找不到學生照片時，圖片顯示區顯示根目錄的 `noPicture.jpg`。

## 門禁記錄

使用者完成登記後，將紀錄寫入文字檔。

單機台記錄檔名格式：

```text
門禁記錄<機台編號>_<日期>.txt
```

範例：

```text
門禁記錄0_20260609.txt
門禁記錄1_20260609.txt
```

日期格式使用西元年月日 `YYYYMMDD`。

每筆資料使用 tab 分隔，欄位如下：

```text
時間	卡片UID	學號	班級	座號	姓名	進/出
```

範例：

```text
08:11:40	?	400001	高一1	16號	範例學生	刷進
```

## 整併記錄

每天中午 `12:10` 自動把所有機台的當日門禁記錄整合成一個檔案。

整併後檔名格式：

```text
門禁記錄_<日期>.txt
```

範例：

```text
門禁記錄_20260609.txt
```

整併規則：

- 讀取當日所有 `門禁記錄<機台編號>_<日期>.txt`。
- 合併後依時間排序。
- 輸出為 `門禁記錄_<日期>.txt`。
- 若同一筆資料重複出現，保留原始資料，不自動去重，避免誤刪實際刷卡紀錄。

## 定時清理與歸檔

系統需定時清理根目錄中的門禁記錄。

規則：

- 找出根目錄中超過 7 天的 `門禁記錄*.txt`。
- 將過期記錄移到該年度資料夾。
- 年度資料夾名稱使用西元年份，例如 `2026`。

範例：

```text
C:\Users\CCSH\Desktop\RFID\2026
```

## 後台功能

後台頁面需要提供：

- 查看今日各機台門禁記錄。
- 查看今日整併後門禁記錄。
- 手動執行整併。
- 手動執行清理歸檔。

## API 規格

建議提供以下 API：

- `POST /api/checkin`
  - 接收 `student_id`、`machine_id`、`direction`。
  - 查詢學生資料。
  - 學號存在時寫入門禁記錄並回傳學生資料與照片 URL。
  - 學號不存在時回傳錯誤，前端顯示 alert。
- `GET /api/student/<student_id>`
  - 查詢學生資料與照片 URL。
- `GET /admin`
  - 顯示後台頁面。
- `POST /api/admin/merge`
  - 立即整併今日所有機台記錄。
- `POST /api/admin/archive`
  - 立即執行過期記錄歸檔。

## 測試情境

- 輸入存在的範例學號，例如 `400001`，應顯示照片、學生資料，並寫入今日對應機台記錄。
- 輸入不存在的學號，應顯示 alert，且不寫入門禁記錄。
- 切換 `刷進`、`刷出`，確認記錄最後欄位正確。
- 切換 `機台0`、`機台1`，確認寫入不同機台檔案。
- 在前台選取今日其中一筆記錄後按 Delete，確認會先詢問。
- 刪除確認後，確認該筆資料從今日對應機台記錄檔移除。
- 刪除取消後，確認記錄檔不變。
- 測試照片副檔名 `.jpg` 與 `.JPG`。
- 找不到照片時，確認顯示 `noPicture.jpg`。
- 手動執行整併，確認產生 `門禁記錄_<日期>.txt`。
- 建立超過 7 天的測試記錄，執行歸檔後確認移入年度資料夾。

## 已確認設定

- 技術選型：Python Flask。
- 登記方式：輸入學號後按 Enter。
- 自動整併時間：每天中午 `12:10`。
- 規格檔編碼：UTF-8。
